# Источники профиля Minecraft 1.7.10

Каталог строится по принципу «полнота из реестра, объяснение из документации, точность из кода».

## Порядок доверия

1. Реестр и код Minecraft Java Edition 1.7.10 — окончательный источник состава игры, чисел и условий.
2. Minecraft Wiki и её история версий — основной источник понятных игроку объяснений и связей между механиками.
3. Структурированные сторонние наборы — контрольная сверка, но не самостоятельное доказательство.
4. Ручной тест в чистом экземпляре 1.7.10 — проверка спорного или неоднозначного поведения.

В каждой статье v2 источник привязывается к конкретному факту через `sourceIds`. Текст формулируется заново, а не
копируется из Wiki.

## Контроль полноты блоков

`knowledge-workbench/vanilla-1.7.10/blocks.json` строится из метода
`net.minecraft.block.Block.registerBlocks` локального исходника Minecraft 1.7.10. Он содержит все 171 фактически
зарегистрированный блок, включая воздух, жидкости, технические состояния и недоступные в обычном выживании блоки.

Числовые ID 165–169 в этой версии свободны. Это важная граница: слизневый блок, барьер, железный люк, призмарин и
морской фонарь относятся уже к 1.8 и не должны попадать в профиль 1.7.10.

Набор `PrismarineJS/minecraft-data` полезен для дополнительной сверки, однако его текущий каталог `pc/1.7` содержит
часть данных 1.8. Поэтому он не используется как первичный перечень и не переносится в профиль автоматически.

## Граница с игровым модом

Инструменты каталога находятся в тестовой части проекта. Они используются разработчиком при подготовке профиля,
не входят в JAR, не запускаются вместе с Minecraft и не заставляют Аврору читать код или реестры установленной игры.
