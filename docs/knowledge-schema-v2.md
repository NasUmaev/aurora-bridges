# Формат знаний v2

`article-v2` — единая оболочка для фактов Minecraft 1.7.10. Она рассчитана на постепенное заполнение каталога:
старые статьи v1 продолжают читаться, а новые сущности создаются в структурированном формате v2.

## Основные поля

- `id` — постоянный уникальный идентификатор статьи;
- `kind` — вид знания: блок, предмет, моб, рецепт, механика и так далее;
- `gameVersion` — точная версия игры;
- `subject` — объект статьи и его реестровые признаки;
- `summary` — короткое человеческое описание;
- `facts` — независимые проверяемые утверждения;
- `relations` — связи с другими статьями;
- `sources` — происхождение фактов.

Каждый факт имеет собственный `key` и ссылки `sourceIds`. Благодаря этому можно исправить одно свойство, не
переписывая всю статью, а в будущем показывать уровень уверенности и точный источник каждого ответа.

## Правила наполнения

1. Одна статья описывает одну сущность или одну механику.
2. Технические ID используются для связей и поиска, но не должны попадать в обычный ответ игроку.
3. Различающиеся metadata-варианты описываются отдельными фактами или отдельными статьями, если их поведение
   существенно различается.
4. Условия дропа, инструменты, Fortune и Silk Touch являются отдельными фактами, а не одним неразборчивым абзацем.
5. У каждого факта должен быть хотя бы один существующий источник.
6. `summary` не должен дублировать все факты; это краткое определение сущности.
7. Синонимы включают русское и английское название, распространённые формы вопроса и реестровое имя.

Формальная JSON Schema находится в `knowledge-schema/article-v2.schema.json`.
